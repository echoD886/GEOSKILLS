# Archetype G — Newsletter Essay / Substack

Calibrated from 5 verbatim audits: Lenny's Newsletter (Ethan Evans guest), Not Boring (Packy McCormick), Tomasz Tunguz, Every (Katie Parrott), Pirate Wires (Mike Solana).

When to use: recurring newsletter publication, Substack-style essay, opinion column, curated weekly roundup. NEVER use for: research notes (use D), product launches (use B), incident reports (use C). Founder essays at < 500 words use the DHH variant in archetype E.

## Two sub-modes — pick ONE

### G.1 — Cozy greeting opener (Lenny / Packy / Every)

```
[Branded greeting + day + multi-topic tease]
"Happy Thursday! A few weeks ago in Not Boring Capital's quarterly LP
update, I wrote a small essay on scarce assets in a period of
abundance."
                          — Packy McCormick, "Scarce Assets"

"Happy Tuesday! Today we have a mini Vibe Check on a tool for running
more than 100 coding agents in parallel. Plus: how to write viral X
posts using the secrets of Grok's algorithm, why Every's chief
operating officer..."
                          — Every, "Inside the 100-agent Software Factory"
```

The greeting IS the brand asset. Same day-of-week every week trains reader expectation.

### G.2 — Cold-open contrarian stake (Tunguz / Solana)

```
[Data-stake, no preamble, no greeting]
"Google's AI triples in price each year. OpenAI's flagship model was
seemingly subsidized for a while, before rising again."
                          — Tomasz Tunguz, "The Unsustainable Subsidy"

"Inspired, I guess, by the cascading disaster that is California's
recently proposed 'billionaire tax'..."
                          — Pirate Wires, "Theory of Power"
```

Cold-open variant signals "this is edge tier, not cozy newsletter." Never mix the two.

## Structure patterns

### Lenny-mode (framework essay with FAQ)

```
1. Host editorial framing (italics, 1-2 paragraphs)
2. Guest thesis sentence
3. Step 1 (own H2)
4. Step 2 (own H2)
5. ... (parallel-structure steps)
6. Advanced forms
7. Common problems
8. FAQ section (inside post, not at end)
9. Soft paywall cut OR conversion gate
```

### Packy-mode (sweeping thesis with parable)

```
1. Greeting + behind-the-scenes tease
2. Macro frame ("Scarce Assets")
3. Sub-frame 1 ("Macro Scarce Assets")
4. Sub-frame 2 ("Positional Scarcity")
5. Historical parable (Federico da Montefeltro)
6. Modern application ("Micro Scarce Assets")
7. Aphoristic close
```

### Tunguz-mode (daily-data micro)

```
- Single block of prose, no H2s
- 3 charts segment the argument (chart caption = section header)
- Under 200 words total
- Copyright line as closer
```

### Every-mode (recurring branded segments)

```
1. Mini-Vibe Check: <topic>          ← branded recurring slot
2. Steal this workflow               ← branded recurring slot
3. Signal                            ← branded recurring slot
4. Inside Every                      ← branded meta-section
```

Named recurring segments REPLACE H2s as the navigational unit. Reader knows the structure of every issue.

### Solana-mode (long contrarian polemic)

```
- No H2s, em-dash chains, parenthetical asides
- First-name policy targets ("Bernie," not "Senator Sanders")
- Performative-casual interjections ("I guess," "look," "anyway")
- Recurring "we covered this first" credit-staking near end
```

## Unique mechanics

- **Multi-CTA layering**: top forwarding notice ("was this forwarded to you?") + mid-body inline subscribe + footer subscribe. 3 placements minimum.
- **Named recurring segments**: "Vibe Check," "Steal this workflow," "Signal" (Every) / "Today's X is brought to you by" (Packy) / "FAQ" inside post (Lenny). These segments are the brand IP.
- **Self-citation as personal canon**: every newsletter essayist back-links to their own prior issues, building closed referential universe.
- **Day-of-week or temporal anchor in opening line**: "Happy Thursday," "Happy Tuesday." Newsletters are explicitly time-stamped in voice; research posts and case studies are timeless.
- **Behind-the-scenes confession in opening**: "A few weeks ago I wrote this for our LP update and it grew..." (Packy). Newsletter readers are inside-the-tent.
- **Soft paywall cuts**: Lenny's variant cuts to "This post is for paid subscribers" right after the FAQ — conversion-engineered ending.
- **Sponsored sections embedded mid-essay**, not top or bottom. ("Today's Not Boring is brought to you by...")
- **Aphoristic religious-cadence close** (Packy): `"Scarce is hard and hard is scarce, forever and ever, amen."`
- **First-person stake in first 50 words**: "I wrote a small essay" / "Today we have" / "Inspired, I guess." Newsletter essay never opens with third-person hook.

## Proof elements

- **Figures**: high variance — Tunguz uses 3 charts to replace H2s; Packy uses 16; Solana uses 0–1; Every uses 2 screenshots; Lenny uses 4 framework diagrams
- **Code blocks**: 0 in essays; may appear in "Steal this workflow" segments (rare)
- **Outbound citations**: 5–35 per post
- **Interview quotes**: common in Every / Lenny; rare in Packy / Tunguz
- **Self-cites**: HIGH across all variants (closed referential universe)

## Closing moves

| Variant | Closing pattern |
|---|---|
| Packy | Aphoristic religious cadence ("forever and ever, amen") |
| Tunguz | Copyright line + social links (legal terseness) |
| Every | Operational utility ("For sponsorships, reach sponsorships@every.to") |
| Lenny | Hard paywall cut |
| Solana | Polemical exhortation, no thank-you |

Never close with a product CTA-with-button. The closer carries brand signature.

## Exclusivity rules for Coherence Gate

These belong ONLY to Archetype G — never in Case Study / Launch / Research / Incident / Strategy:

1. **"Hi friends 👋" / "Happy Thursday!" / "Happy Tuesday!" greeting opener with sender's first name** — exclusive to newsletter cozy variant; reads as unprofessional in any other archetype
2. **Multi-topic "Plus:..." tease in sentence two** — Every's signature; never in single-topic Case Study or Launch
3. **"Thanks for reading drafts" credit line** — newsletter signature; jarring in Case Study or Research
4. **Day-of-week temporal anchor** ("Happy Tuesday") — newsletter only; research/case study is timeless
5. **Named recurring segments** ("Vibe Check," "Steal this workflow," "Signal") — brand IP exclusive to a specific newsletter; do NOT invent these for one-off posts
6. **Mid-essay sponsored block** ("Today's X is brought to you by...") — newsletter only; never in research/launch
7. **Soft-paywall cut closing** ("This post is for paid subscribers") — newsletter only
8. **First-name policy targets** ("Bernie," not "Senator Sanders") — Solana-variant only

## Word count targets

| Variant | Target |
|---|---|
| G.1 framework essay with FAQ (Lenny) | 3,000–4,500 |
| G.1 sweeping thesis with parable (Packy) | 5,000–8,500 |
| G.1 curated roundup (Every) | 1,500–2,500 |
| G.2 daily data micro (Tunguz) | 150–300 |
| G.2 contrarian polemic (Solana) | 2,500–5,000 |

## When to refuse this archetype

- If the publication is not a recurring newsletter / Substack → write Strategy (F) or Founder Essay (E) instead
- If the topic warrants a single-topic deep treatment → don't pad with multi-topic teases
- If the writer doesn't have a closed referential canon to back-link → newsletter falls flat (write standalone Strategy F instead)
