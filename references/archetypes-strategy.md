# Archetype F — Strategy / Industry Analysis

Calibrated from 5 verbatim audits: Stratechery (Ben Thompson), Benedict Evans, a16z (Anish Acharya), Sequoia Capital (Jack Dorsey × Roelof Botha), Stratechery × John Collison interview.

When to use: market analysis, industry-shift essays, framework-drop think pieces, VC perspective posts. NEVER use for product launches, case studies, or research notes.

## Verbatim opening patterns (pick ONE)

```
[Contrarian rebuttal anchored to a dated outside claim]
"In January 2025, Doug O'Laughlin at Fabricated Knowledge declared
that o1 and reasoning models marked the end of Aggregation Theory."
                          — Stratechery, "Mythos, Muse..."
```

```
[Enumerated-question framework drop]
"It seems to me that OpenAI has four fundamental strategic questions.
First, the business as we see it today doesn't have a strong, clear
competitive lead."
                          — Benedict Evans, "How will OpenAI compete?"
```

```
[Principle assertion + market observation]
"At Sequoia, we see that speed is the best predictor of start-up
success. Most companies are focused on AI as a productivity
enhancer. Few are focused on the potential of AI to change how we
work together."
                          — Sequoia, "From Hierarchy to Intelligence"
```

```
[Peer-citation + temporal framing]
"I enjoyed the 2025 roundup pieces from Karpathy, Simon and many
others, and they have me thinking about 2026."
                          — a16z, "Notes on AI Apps in 2026"
```

Banned openings for this archetype: "Last week X happened" (chronological news lede), "In this post we will explore" (throat clearing), "Have you ever wondered" (rhetorical drift).

## H2 sequence patterns

Two valid sub-modes — pick one and don't mix:

**Sub-mode F.1 — Econ-concept ladder (Stratechery / Sequoia)**

```
1. Concept A definition           (re-grounds reader in economics/history)
2. Concept B definition           (introduces the new frame)
3. Case proof point 1
4. Case proof point 2
5. Synthesis section resurrecting the named framework
```

**Sub-mode F.2 — Sectionless prose with asterisk breaks (Evans / Sequoia "Hierarchy")**

```
No H2s. Asterisk visual breaks (* * *) between sections.
Numbered argument scaffolding ("First, Second, Third") inside paragraphs.
Historical analogies stacked: Netscape → TSMC → Intel → Romans → Prussians.
```

**Sub-mode F.3 — Mini-thesis H2s (a16z)**

```
1. Thinking tools vs Making tools
2. Software eats all the "service" functions in the organization
3. Compounding AI apps
4. Humans discover "the rest" of AI
5. Notes for (incumbent) CEOs
6. Finally … have fun
```

Each H2 = a quotable mini-thesis, not a topical label.

## Unique mechanics (signature moves)

- **Named, capitalized framework as recurring proper-noun character**: "Aggregation Theory," "opportunity cost of compute," "Roman contubernium," "McKinsey 7-S," "Thinking tools vs Making tools," "four strategic questions."
- **Self-citation is the citation strategy**: Stratechery posts have ~8 self-cites, the Collison interview has ~55. Strategy authors build recursive framework graphs.
- **Historical/cross-industry analogy as dominant proof mode**: Netscape vs Microsoft, TSMC, Romans, Manhattan Project. Not benchmarks.
- **Two-author bylines on Sequoia variant**: VC partner + founder. The founder's company becomes embedded case study.
- **Asterisk visual breaks** between sections (Evans). No H2s at all.
- **Inline numbered scaffolding** ("First, Second, Third, Fourth") inside paragraphs, not as bullets.

## Proof elements

- **Charts**: Two valid postures — Evans-mode (9+ charts, data-heavy) OR Thompson/Sequoia-mode (0 charts, prose-only). Never half-commit with 1-2 token charts.
- **Code blocks**: 0. Strategy archetype suppresses code formatting even when discussing software.
- **Outbound citations**: Press (Bloomberg / WSJ / The Information / Economist), not docs/GitHub.
- **Self-cites**: HIGH. 7-55 per post. The closed referential universe is the moat.
- **Portfolio embedding** (VC variant only): Sequoia uses Block as the literal next-sentence proof point.

## Closing move

Closing = a wager, aphorism, or portfolio name-drop. NEVER a summary.

- Thompson: `"my bet is that owning demand will ultimately trump owning supply, suggesting that the underlying principles of Aggregation Theory lives on."`
- Evans: `"Intel had a network effect, and then it didn't, and it had a technology lead, and then it didn't."`
- Sequoia: `"Block is building what comes next."`
- a16z: `"No one tells you that you are living in the good old days until they are gone, so consider this your notice."`

## CTAs

- Independent analyst variant (Thompson, Evans): **footer subscribe only**, no mid-article CTA
- VC variant (a16z, Sequoia): inline newsletter sidebar OK; the post itself functions as the soft pitch
- **No hiring CTA. No "try the product." No "sign up now."**

## Exclusivity rules for Coherence Gate

These belong ONLY to Archetype F:

1. **Naming and capitalizing a framework as a recurring proper-noun character** — never invent new "Theories" in Launch / Case Study / Incident archetypes
2. **Self-citation density ≥ 7 per post** — Case Study has 0 self-cites, Incident has 0
3. **Asterisk-break sectionless prose** — never use in any other archetype
4. **Two-author VC + founder byline** — exclusive to Sequoia-style strategy; Case Study can have 2 engineering authors but never VC + founder
5. **Closing wager naming 3+ public companies** — only in strategy ("My bet is X over Y vs Z")

## Word count targets

| Variant | Target |
|---|---|
| Independent analyst essay | 1,800–4,200 words |
| VC perspective post | 1,800–2,400 words |
| Interview transcript | 6,000–18,000 words (TOC-like H2s required) |

## When to refuse this archetype

- If the writer has no named, capitalized framework to propose or extend → kill, write a different archetype
- If the writer has no historical analogy or cross-industry parallel → kill
- If the writer wants to embed a product CTA → wrong archetype, write a Launch or Case Study instead
