# 中文原型 — Chinese Native Archetypes (zh-CN)

Calibrated from 7 verbatim audits of top Chinese tech / business / curation blogs:
36kr / 虎嗅 / 极客公园 / 阮一峰科技爱好者周刊 / 少数派 / SegmentFault 思否 / 知乎专栏长文.

**核心原则：中文 blog 不是英文 blog 的翻译。** 每个 locale 跑自己的关键词调研、用自己市场的真实平台引用、用本地权威信号、写本地化标题公式。把英文 archetype 直译到中文 = 翻译腔，搜索引擎 + 用户 + 中文 LLM 都识别得出来。

This file lists 3 Chinese-native archetypes + 10 exclusivity rules for things that NEVER cross-translate.

---

## 中文 Archetype K — 深度商业报道 (Chinese Deep Report)

适用：36kr、虎嗅、极客公园、少数派、思否这种 1500–18000 字的深度文。

### 标题公式（5 种真实模板）

```
[冒号断句 + 反问 + 引号反讽]
"苹果：AI缺位、存储涨价，照样"稳稳幸福"？"
                                — 36氪

[数字 + 短语 + 动词]
"2026年，7个趋势正在爆发"
                                — 虎嗅

[长定语 + 冒号 + 副标]
"2026年5月 AI 搜索重构商业流量分配：GEO 专业服务商五强深度解盘与选型战略"
                                — 极客公园

[期数 + 冒号 + 金句]
"科技爱好者周刊（第 395 期）：软件开发的第三种方式"
                                — 阮一峰

[祈使否定 + 武断比喻]
"别再盯着聊天框了！2026年，具身智能正在撕毁 AGI 的最后一张考卷"
                                — 知乎专栏长文
```

**禁用**：英文直译型标题（"Apple Q2 Earnings Analysis"、"7 Trends in 2026"）— 在中文 SERP 上极度不出色。

### H2 结构

中文深度文 H2 的两种形态都对，挑一种**不要混**：

**形态 K.1 — 中文序号 + 冒号**

```
1. 海豚君整体观点：iPhone 17爆火，关注新Siri能否补齐AI短板
2. 一、苹果的基本盘，依然"很强"！
3. 二、iPhone：中国市场热销，实现逆势增长
4. 三、iPhone 以外其他硬件：重回增长
5. 四、软件服务："生态壁垒"稳固，期待新Siri
```

**形态 K.2 — 冒号断句 + 主副短语**

```
1. AI硬件上桌：眼镜、机器人、3D打印机
2. 稳定慢增长：消费与文娱，被技术重新激活
3. 远期投入：商业航天和低空经济
```

### 段落韵律（与英文 blog 关键差异）

中文段落**显著更短**：一段 1–3 句，每句 15–40 字。"。" 和换行密度远高于英文。英文一段 200 字，中文常拆 5 段。少数派、虎嗅、36氪 都遵守。

### 作者人称

| 平台 | 主流人称 |
|---|---|
| 个人 blog（少数派 / 阮一峰） | "我" |
| 商业媒体（36氪 / 虎嗅 / 极客公园） | "我们" / "笔者" / 品牌虚拟人称（"海豚君"） |
| 大模型评测 / 行业分析 | "笔者" + 编辑部署名（"定焦One团队 / 编辑：魏佳"） |

**禁用**：英文 SaaS blog 主流的"You"对话式（"Here's what you can do today..."）— 中文不自然，必须换成"你可以这样做"或第三人称。

### 数据呈现

**图片主导，HTML 表格罕见**：36氪 11 张 / 阮一峰 27 张 / 少数派 12 张 / 极客公园 5 张。微信复制粘贴图表生态成熟，中文读者习惯截图而非表格。

### CTA 风格

**软 CTA 主导，位置在文末**：

- 虎嗅 → "赞赏开启赞赏支持一下" / "在 虎嗅APP"
- 36氪 → APP 下载条 + "相关推荐 9 篇"
- 极客公园 → 未来时威胁式（"AI 的浪潮不会等待，你今日的选型..."）
- 少数派 → "编者注 + 关注" + Pi Store CTA

**禁用**：英文 SaaS 硬 CTA "Sign up free now" 直译 = "立即免费注册" 中文 SERP 上看着像 dropshipping 商店。换成 "了解更多" / "扫码体验" / "关注我们"。

### 作者权威信号（三件套必备）

中文顶级 blog 的作者 bio 比英文重得多：

```
✅ 海豚投研 / 特邀作者 / 已发表 1252 篇
✅ 主理人 Lau Joe / 公众号 + 博客
✅ 定焦One / 编辑：魏佳
✅ 前华为 / 现某 AI 团队 / 5 年硬件经验

❌ "by Jacob" 直译 = "作者：Jacob"  (太轻，没权威)
```

机构 + 角色 + 数字证据 = 中文权威标配。

### 平台引用源

中文顶级 blog 引用的数据源（**英文直译会暴露**）：

| 中文引用 | 英文等价 | 备注 |
|---|---|---|
| 艾瑞咨询 | Statista | 别直译，artificially translation tell |
| QuestMobile | App Annie / data.ai | 中文专用 |
| 易观 / 极客公园数据库 | Gartner | 中文专用 |
| CNNIC | Pew | 中文专用 |
| 招股书 | S-1 filing | 中文常引用 |
| 36氪研究院 / 虎嗅Pro / 亿欧智库 | TechCrunch reports | 中文专用 |

### 收尾

中文文气：四字短句 / 比喻收尾。**禁用**直译的英文 imperative ("Take action today")。

```
✅ "一块完全属于自己的、利于深度思考与知识生产的自治领地。这便是对生产力祛魅的最深刻实践。"
                          — 少数派

✅ "AI 的浪潮不会等待，你今日的选型，将直接刻画几年后你的品牌在新一代用户心智中的存在方式。"
                          — 极客公园

✅ "谁能把 AI 稳定、可靠、可持续地运行在真实业务系统中。这，正是 2026 年被称为 AI 应用元年 的真正原因。"
                          — 思否
```

## 中文 Archetype L — 周刊 / Curated Weekly（阮一峰风）

### 模板（12 个固定栏目，期期一样）

```
封面图 → 头条专文 → 大模型流行度排行榜 → 科技动态
     → 文章 → 工具 → AI 相关 → 资源 → 图片 → 文摘
     → 言论 → 往年回顾 → 文档信息 → 相关文章 → 留言
```

**模板就是品牌**。每期 12 个栏目，读者训练完毕。**首期开始不能换栏目**，每周必须模板化。

### 开场

模板式：

```
"这里记录每周值得分享的科技内容，周五发布。本杂志开源，欢迎投稿。
另有《谁在招人》服务，发布程序员招聘信息..."
                          — 阮一峰科技爱好者周刊
```

每期完全相同的开头 = 强品牌。

### 独特机制

- 第一人称 "我" + 编号 # 注释（"#1" 开头）
- "言论" 和 "文摘" 区域 = 纯引语集
- 公开 "往年回顾" 区
- 留言区 42 条公开展示（社区资产）

### 与英文 newsletter 的关键差异

| 维度 | 英文 newsletter（Lenny / Packy） | 中文周刊（阮一峰） |
|---|---|---|
| 开场 | "Happy Thursday!" 短问候 | 完整自我介绍 + 投稿说明 |
| 段落 | 中长段（3–5 句） | 极短（1–2 句） |
| 多 CTA | 顶部 + 中部 + 底部 3 处 | 文末单 CTA + 留言区 |
| 自引 | 高（"in last week's issue"） | 低（"往年回顾" 区集中处理） |
| 平台 | Substack 付费墙 | 个人博客 + RSS + 邮件订阅 |

## 中文 Archetype M — 知乎长文（Zhihu Longform）

### 标题公式

```
[祈使否定开头]
"别再盯着聊天框了！"

[利益相关 + 数字]
"2026年，"

[武断动词]
"撕毁"

[比喻名词化]
"最后一张考卷"
```

完整标题：`别再盯着聊天框了！2026年，具身智能正在撕毁 AGI 的最后一张考卷`

### 知乎平台特有模式

- **"利益相关"披露**：开头第一段必须坦白作者身份（"利益相关：在某 AI 公司做 Agent" / "利益相关：被 Y Combinator 投过"）
- **作者认证徽章**："科大博士" / "前华为" / "知乎科技话题优秀回答者" 必须出现在 byline 旁
- **TOC 折叠 + 小标题图**：中段插入小图分节
- **文末硬 CTA**："觉得有用点个赞" / "关注我看更多" — 比 36氪 / 虎嗅 都硬，因为知乎评论权重计算
- **评论区精选置顶**：评论本身是 SEO 资产，作者主动维护

## 中文 Exclusivity 规则（10 条）

这 10 个动作只能用在中文 locale，跨用到英文版会被识别为"翻译稿"，搜索引擎不引用，LLM 不引用：

1. **"震惊体" / 反问体标题**（`"稳稳幸福"？` / `别再 X 了！`）— 仅中文 locale；英文 `"Is Apple Still Lucky?"` 会显得幼稚
2. **公众号 QR 卡片 + "扫码关注"**（36氪、极客公园、少数派标配）— 英文版绝不能有，替换为 newsletter signup
3. **"一/二/三/四" 中文数字序号 H2**（极客公园、思否标配）— 英文应改为 "1. 2. 3." 或意译
4. **"前 XXX 公司 / 主理人 / 特邀作者 / 已发表 N 篇" 权威三件套**— 中文必备；英文版应改为 `"Previously at X, currently building Y"`，去掉发文数
5. **「书名号」包裹概念词**（少数派的「本地、稳定、可迁移」）— 英文必须改为 *italics* 或 `"quoted"`
6. **"赞赏 / 打赏" 按钮 / Pi Store CTA**（虎嗅、少数派）— 英文版应替换为 `"Buy me a coffee"` 或删除
7. **"截至 2026 年 5 月，X 突破 Y" 时间锚 + 中文机构数据**（艾瑞 / QuestMobile / CNNIC）— 中文标配；英文应换 Statista / Gartner 且改美式日期
8. **冒号嵌套主副标**"长定语：核心概念解盘"（极客公园式）— 英文应拆成 title + subtitle 两行
9. **"海豚君 / 笔者 / 编辑部" 虚拟人称**— 中文专属；英文必须用 `I` 或 `We`，`"This editor"` 翻译腔太重
10. **结语用四字短句 / 比喻收尾**（"自治领地"、"会做系统的人"、"刻画品牌存在方式"）— 中文文气；英文应改为具体行动号召

## 中文 AI 引用友好度（百度文心 / Kimi / 通义偏爱）

中文 LLM 引用中文 blog 时的偏好（基于观察 + 上述 7 篇被引用情况）：

1. **"一/二/三/四" 序号 H2**（极客公园、思否、36氪 全员遵守）
2. **冒号 + 短语 H2**（搜索引擎切片友好）
3. **段落 1–3 句**（便于 chunk）
4. **结语金句化**（"会做系统的人" 被反复 quote）
5. **"截至 YYYY 年 M 月" 时间锚**（极客公园开头就有）
6. **"X 突破 Y" 数据爆点**（"中国生成式 AI 用户突破 5.15 亿"）
7. **机构 + 编辑名权威三件套**（让 LLM 知道引用谁）

## 使用本文件

写中文 blog 之前：

1. 选 K（深度报道）/ L（周刊）/ M（知乎长文）中的一个
2. 抄那个 archetype 的标题公式（不是直译英文标题）
3. 段落韵律切到 1–3 句短段
4. 作者人称用中文标配（"我们" / 品牌虚拟人称）
5. 引用源换成中文版（艾瑞 / QuestMobile / CNNIC，不是 Statista / Gartner）
6. CTA 改软（"扫码关注" / 赞赏 / 编者注，不是 "Sign up free"）
7. 收尾用四字短句 / 比喻，不是 imperative

**做不到原生 = 不发**。直译稿即便上线，中文 SERP 也排不上去。
